# Stable release with bug fixes

This maintenance release fixes playlist generation and server timezone handling.

- Fixed “This Is” playlist creation failing with `name 'candidate_tracks' is not defined` when the AI service failed or returned an invalid response (#62). The app now falls back to the artist's most-played tracks and explains that fallback in the playlist description.
- Fixed server-level playlist refresh scheduling through the `TZ` environment variable (#61). Cron checks, next-refresh calculations and due-playlist checks use the same named timezone, including daylight-saving rules.
- Fixed opening or refreshing the Genre Mix page directly.
- Fixed keyless OpenRouter configuration so the existing local curation fallback can run.
- Added automated regression tests and Docker publishing for Intel/AMD (`linux/amd64`) and Apple Silicon/ARM (`linux/arm64`).

## Docker update

Images are available as `rickysynnot/magic-lists-for-navidrome:1.4.3`, `:v1.4.3`, `:stable` and `:latest`.

For an image-based Docker Compose installation:

```sh
docker compose pull
docker compose up -d
```

Set `TZ=America/New_York` (or another IANA timezone such as `Australia/Melbourne`) in the container environment to select the server timezone. Recreate the container after changing it. This applies to the whole instance; there is no GUI or per-user timezone selector. Existing schedule dates remain local wall times in the selected timezone.

Keep your existing database volume and Navidrome configuration. No Song Radio or demo-only features are included in this release.
